# DevLukeOps - Portfólio de DevOps

Bem-vindo ao **DevLukeOps**, meu projeto de portfólio para demonstrar habilidades em DevOps! Meu nome é Lucas, e aqui atuo como a ponte entre Desenvolvimento (Dev) e Operações (Ops), aplicando práticas modernas de automação, CI/CD e monitoramento.

## Objetivo
Criar uma plataforma que provisiona infraestrutura no Azure, implanta uma aplicação de teste em Docker, automatiza processos com GitHub Actions e monitora tudo com Prometheus e Grafana.

## Tecnologias
- **Terraform**: Provisionamento de infraestrutura.
- **Ansible**: Configuração de servidores.
- **Docker**: Conteinerização.
- **GitHub Actions**: Pipelines CI/CD.
- **Prometheus e Grafana**: Monitoramento.
- **Python**: Scripts e aplicação de teste.
- **Bash**: Automação local.
